# Thư Mục Bản Đồ Tương Tác Địa Chấn (Leaflet Map)

Thư mục này chứa component bản đồ Leaflet:
- Hiển thị các chấn tâm động đất toàn cầu dạng Marker / CircleMarker.
- Phân loại màu sắc theo độ sâu (Depth) và kích thước theo thang độ Richter (Magnitude).
- Hỗ trợ Popup thông tin chi tiết và liên kết dữ liệu thời gian thực (SSE).
