# Thư Mục Thành Phần Giao Diện Cơ Bản (UI Primitives)

Chứa các component giao diện dùng chung trong hệ thống:
- `Button`: Nút thao tác chuẩn giao diện tối
- `Card`: Khung chứa biểu đồ và dữ liệu
- `Navbar`: Thanh điều hướng đầu trang
- `Sidebar`: Thanh bên chuyển đổi chức năng
- `Badge`: Nhãn trạng thái dữ liệu (độ sâu, mức rủi ro)
